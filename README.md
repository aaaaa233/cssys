# CSSys - 计算机系统结构实验框架

本项目是一个基于 gem5 的计算机系统结构实验框架，用于开展从缓存到加速器的各项体系结构实验。

## 项目简介

CSSys（Computer System Structure）是一个模块化的计算机体系结构仿真平台，通过 gem5 模拟器实现对处理器、缓存层次结构和自定义硬件加速器的建模与分析。项目包含 7 个递进式的实验模块，涵盖：

- CPU 模型对比与保真性分析
- 缓存层次结构设计（关联度、替换策略、预取）
- 分支预测器设计
- 硬件加速器（Dotp8）设计与优化
- 系统集成与性能评估

## 核心组件

### 1. 基准测试程序

- **pchase**: 指针追踪测试，评估缓存访问效率
- **stream**: STREAM 内存带宽基准
- **gemm**: 矩阵乘法，评估计算性能
- **qnn**: 8 位量化神经网络推理（MLP）
- **branchy**: 分支密集型程序

### 2. Dotp8 加速器

自定义 8 位向量点乘硬件加速器，支持：

- 可配置的处理单元数量（PE）
- 异步 FIFO 请求队列
- 可调的启动延迟与吞吐量

### 3. 参数扫描框架

`framework/sweep.py` 支持灵活的参数空间扫描，可同时变化硬件配置和软件（二进制），实现软硬件参数的笛卡尔积实验。

## 快速开始

### 环境要求

- gem5 仿真器
- Python 3.x
- SCons 构建系统

### 编译 gem5

```bash
cd _tools
./build_gem5.sh
```

### 运行实验

```bash
# 运行 Lab 1 实验
./run_lab1.sh

# 运行指定基准测试
./run_lab5.sh qnn timing
```

## 技术细节

### 缓存配置

框架支持灵活的三级缓存配置：

- L1 I/D Cache：可配置关联度、容量、替换策略
- L2 Cache：统一缓存，支持预取器
- 可选的 L3 Cache

### CPU 模型

- **TimingSimpleCPU**: 简单时序模型
- **O3CPU**: 乱序执行处理器，支持可配置流水线宽度、ROB 容量、发射队列深度等
